# UmbreRumble
対戦型3dアクションミニゲーム

傘で戦うバトロワ。ラッパ傘にならないようにアクションで相手をステージ外に落とし最後まで生き残れ。

環境：windos
必須外部機器：xboxコントローラー1~4台または任天堂プロコン1～4台
注意事項：ゲームを起動したままコントローラーの接続を増やすとゲームが落ちます。プログラムの都合でpc本体のスクリーンの大きさを100%の1920×1080にしないと画面サイズがおかしくなる可能性あり。
        　一部動作が重くなる場合があるのでノートpcで起動する場合は充電しながらのプレイをお勧めします。
